## Featured Projects

### 1. Multi-Horizon Asset Price Forecasting & Risk Analysis

A cross-asset forecasting project covering TSLA, GOOGL, BTC and ETH.

The project compares Random Forest and ARIMA across multiple forecasting horizons, using leakage-safe chronological evaluation, simple forecasting benchmarks and Monte Carlo simulation to assess both predictive performance and uncertainty.

**Key themes**
- Multi-horizon forecasting
- Time-series modelling
- Machine learning
- Out-of-sample model validation
- Benchmark comparison
- Forecast uncertainty
- Equity vs cryptocurrency market behaviour

**Key finding:** More complex models did not consistently produce better out-of-sample performance, particularly for high-volatility crypto assets.

- [View Full Report](https://andywangprojects.github.io/multi-horizon-asset-price-forecasting/report/Task1000_Multi_Horizon_Asset_Forecasting_Report.html)
- [View GitHub Repository](https://github.com/andywangprojects/multi-horizon-asset-price-forecasting)

### 2. Cross-Sector ETF Risk Analysis

A comparative risk study of technology, financial and energy sector ETFs using XLK, XLF and XLE.

The project evaluates sector-level risk and return characteristics using Sharpe Ratio, Value at Risk, Conditional Value at Risk and Maximum Drawdown.

**Key themes**
- Market risk
- Sector comparison
- Downside-risk analysis
- Risk-adjusted performance
- Volatility interpretation

The analysis found clear differences between growth-oriented technology exposure, relatively more stable financial-sector behaviour and the cyclical risk characteristics of energy markets.

- [View Report](https://github.com/andywangprojects/cross-sector-etf-risk-analysis/blob/main/report/Cross_Sector_ETF_Risk_Analysis_Report.md)
- [View GitHub Repository](https://github.com/andywangprojects/cross-sector-etf-risk-analysis)

---

### 3. Credit Card Fraud Detection & Financial Risk Analysis

An independent project examining how predictive models can support fraud-risk decisions under severe class imbalance.

The analysis uses 1.84 million synthetic credit-card transactions and compares Logistic Regression and Random Forest, with particular focus on the trade-off between missed fraud cases and false alerts.

**Key themes**
- Fraud risk
- Cost-sensitive decision-making
- Classification models
- Threshold analysis
- Model interpretability
- Financial model governance

The project also reviews fraud-prevention and model-risk guidance from Mastercard and the U.S. Federal Reserve to understand how predictive models should be applied within a regulated financial environment.

- [View Full Project](https://andywangprojects.github.io/fraud_detection_project/)
- [View GitHub Repository](https://github.com/andywangprojects/fraud_detection_project)
